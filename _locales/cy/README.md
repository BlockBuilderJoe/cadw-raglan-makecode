# Welsh (cy) tutorial mirrors

This folder is empty on purpose.

A Welsh mirror of a tutorial is `_locales/cy/<same-name>.md` (for example `_locales/cy/q2c-bells.md`). It is added only from Welsh supplied by Sarah (Cadw). Never add placeholders, Lorem Ipsum or machine translation.

A mirror keeps the English file's metadata, headings, step order and code fences exactly. Only the learner-facing text changes. Register the mirror in `pxt.json` `files` and bump `version` in the same change. Test it with `liveforcelang=cy&skipgithubcache=1`.
